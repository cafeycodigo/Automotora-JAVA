Las 5 pruebas de AutomotoraDAO

JUnit ejecuta cada método marcado con @Test. Las aserciones comparan el resultado real con el esperado. Las pruebas del modelo revisan las reglas de una ficha y las del DAO comprueban cómo se guarda y recupera en memoria.

Modelo · VehiculoTest.java

  • normalizaLaPatente() comprueba que " abcd12 " se guarda como "ABCD12".
  • rechazaUnCodigoConLetras() espera una IllegalArgumentException al usar 8820260A.
  • rechazaUnAnioAnteriorA2015() espera una IllegalArgumentException al ingresar 2014.

DAO · VehiculoDAOTest.java

  • encuentraLaFichaGuardada() guarda un Ferrari F8 Tributo y verifica que la búsqueda por ABCD12 devuelve la misma ficha.
  • rechazaUnaClaveDuplicada() guarda dos fichas con patente ABCD12. El primer guardado debe devolver true y el segundo, false.

Ejemplo del modelo

@Test
void normalizaLaPatente() {
    Vehiculo vehiculo = new Vehiculo();
    vehiculo.setPatente(" abcd12 ");
    assertEquals("ABCD12", vehiculo.getPatente());
}

assertEquals compara el texto esperado con el devuelto por getPatente(). Debajo puedes ver el ejemplo completo del DAO para el contexto seleccionado.

Qué aserciones tiene JUnit 5 y cuándo usarlas

Una aserción expresa qué debe ocurrir. En assertEquals(esperado, obtenido), escribe primero el valor que exige la regla y después el resultado del código. Si la patente obtenida fuera abcd12, JUnit indicaría que esperaba ABCD12 y mostraría el valor recibido.

Las cinco pruebas del módulo usan assertEquals, assertThrows, assertTrue, assertFalse y assertSame. El catálogo incluye otras aserciones para escribir casos nuevos.

Valores, referencias y resultados

  • assertEquals y assertNotEquals comprueban igualdad o diferencia de valores. Ejemplo del modelo: assertEquals("ABCD12", vehiculo.getPatente()).
  • assertSame y assertNotSame comprueban si dos referencias apuntan al mismo objeto o a objetos distintos. assertSame(ficha, dao.buscar("ABCD12")) exige recuperar la instancia guardada.
  • assertTrue y assertFalse esperan un resultado booleano. El primer guardar debe devolver true y el segundo con la misma patente, false.
  • assertNull y assertNotNull comprueban ausencia o presencia de un objeto. En un DAO vacío, assertNull(dao.buscar("ABCD12")) comprueba una búsqueda sin resultado.

Excepciones, colecciones y tiempo

  • assertThrows acepta el tipo de excepción indicado o un subtipo. assertThrowsExactly exige el tipo exacto y assertDoesNotThrow comprueba que la operación termina sin lanzar una excepción.
  • assertArrayEquals compara elementos de arreglos. assertIterableEquals compara elementos de iterables en orden. assertLinesMatch compara listas de líneas y permite patrones en las esperadas.
  • assertAll agrupa comprobaciones y reporta sus fallos juntos. Por ejemplo, puede comprobar la patente y el año de una misma ficha.
  • assertTimeout mide la duración y comprueba el límite al terminar. assertTimeoutPreemptively ejecuta en otro hilo e intenta interrumpirlo al superar el límite.
  • fail marca el test como fallido cuando la ejecución llega a un punto inesperado.

Ejemplo de una excepción esperada

assertThrows(IllegalArgumentException.class,
        () -> vehiculo.setAnio(2014));

La expresión () -> entrega a JUnit la operación que debe ejecutar. El test pasa si setAnio(2014) lanza la excepción esperada. Falla si acepta el año o lanza una excepción de otro tipo.

Ejecutar las pruebas y generar cobertura con JaCoCo

El pom.xml de AutomotoraDAO incluye JUnit Jupiter, Surefire y JaCoCo 0.8.14. Maven descarga los complementos en la primera ejecución. Desde la raíz del repositorio ejecuta:

mvn -f AutomotoraDAO/pom.xml test
mvn -f AutomotoraDAO/pom.xml clean verify

El primer comando ejecuta las pruebas. El segundo también genera AutomotoraDAO/target/site/jacoco/index.html. Abre el informe y selecciona Vehiculo o VehiculoDAO para revisar qué líneas y ramas se ejecutaron. Las aserciones de JUnit comprueban el resultado de cada caso.

En NetBeans, abre el módulo AutomotoraDAO y usa Test para correr las pruebas. Para generar el informe, ejecuta los objetivos Maven clean verify.
