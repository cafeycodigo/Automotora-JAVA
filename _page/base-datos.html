Lección 04 · Conexión a base de datos

Conecta Java con una base de datos

Usa MySQL si tienes un servidor local o Supabase si tienes un proyecto PostgreSQL alojado. La selección cambia el código y los pasos de esta lección.

Dependencia en pom.xml · . Al abrir o compilar el proyecto, Maven descarga el controlador.

  1. 1. Crear el proyecto Maven y la tabla

  2. 2. Cargar el controlador y abrir la conexión

    Copia la dependencia al bloque <dependencies> de tu pom.xml. Maven pone el controlador al alcance de Java y ConexionBD abre la conexión con DriverManager.

  3. 3. Guardar y recuperar desde el DAO

    PreparedStatement asigna un valor a cada ?. ResultSet permite reconstruir un objeto con los datos de una fila. try-with-resources cierra los recursos.

  4. 4. Conectar la vista Swing

    Como siguiente ejercicio, crea un JFrame en NetBeans. El formulario construye el objeto, los botones llaman al DAO y un JTable muestra el resultado de listar().

Flujo de datos · Vista o main → DAO → ConexionBD → MySQL

Estructura de carpetas

Guarda pom.xml y esquema.sql en la raíz del proyecto. Los archivos Java van en src/main/java, en la carpeta que corresponde al package de cada clase.

Cuando agregues la vista Swing, créala en src/main/java/cl/automotora/vista. Las pruebas JUnit van bajo src/test/java.

        Ejecutar en NetBeans con Supabase
        
    
          
  1. En el panel de tu proyecto Supabase, abre SQL Editor y ejecuta esquema.sql. La tabla se crea en el esquema public con seguridad por filas activada para el acceso por la API.
    2. 
          
  2. Abre Connect → Session pooler y toma de ahí el host, el puerto y el usuario. Usa la contraseña de la base de datos del proyecto.
    3. 
          
  3. Define estas variables en el entorno desde el que inicias NetBeans. Sustituye los campos de ejemplo por los de tu proyecto y conserva la contraseña fuera del código.
    4. 
        

        
SUPABASE_DB_URL=jdbc:postgresql://HOST_DEL_POOLER:5432/postgres?sslmode=require
SUPABASE_DB_USER=postgres.REFERENCIA_DEL_PROYECTO
SUPABASE_DB_PASSWORD=CONTRASEÑA_DE_LA_BASE

        
Abre el proyecto Maven con el pom.xml de Supabase, copia los archivos Java y ejecuta la clase principal. Comprueba la fila con el SELECT del esquema en el SQL Editor.
