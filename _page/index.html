      01 / El modelo primero
      
          
      Un vehículo es una ficha con reglas.
      
          
      
            La clase Vehiculo representa cada auto del inventario. Reúne sus datos —código, patente, marca, modelo, año, tipo, color, transmisión y estados— y valida algunos de ellos antes de aceptarlos.
          
      
        
      

        
      
          
      
            Validación 01
            
      Código
      
            
      Debe tener exactamente 8 caracteres y todos deben ser dígitos.
      
          
      
          
      
            Validación 02
            
      Patente
      
            
      Se convierte a mayúsculas y debe tener 6 caracteres: formato AAAA12 o AA1234.
      
          
      
          
      
            Validación 03
            
      Modelo y año
      
            
      El modelo debe tener al menos 2 caracteres y el año no puede ser anterior a 2015.
      
          
      
        
      

        
      
          
      
            
      Vehiculo.java · constructor
      
            
      public Vehiculo(String codigo, String patente,
        String marca, String modelo, int anio,
        boolean electrico, boolean disponible,
        String tipo, String color, String transmision) {
    setCodigo(codigo);
    setPatente(patente);
    setMarca(marca);
    setModelo(modelo);
    setAnio(anio);
    setElectrico(electrico);
    setDisponible(disponible);
    setTipo(tipo);
    setColor(color);
    setTransmision(transmision);
}
      
          
      
          
      
            
      ¿Qué ocurre al llamar a new Vehiculo(...)?
      
            
        
              
      1. 1.Java entra al constructor con los 10 valores que recibió.
        2. 
              
      2. 2.El constructor llama a cada setter; no asigna esos campos directamente.
        3. 
              
      3. 3.Cada setter comprueba o prepara su valor y lo guarda en this.campo.
        4. 
              
      4. 4.Si una regla falla, el setter lanza una excepción: la creación no termina normalmente y el objeto no llega a asignarse a la variable.
        5. 
            
      
          
      
        
      

        
      
          
      
            
      Código: comprobación en dos pasos
      
            
      if (codigo == null || codigo.length() != 8) {
                throw new IllegalArgumentException(
                    "El código debe tener exactamente 8 dígitos.");
            }
            for (int i = 0; i < codigo.length(); i++) {
                if (!Character.isDigit(codigo.charAt(i))) {
                    throw new IllegalArgumentException(
                        "El código solo puede contener números.");
    }
}
this.codigo = codigo;
      
            
      Primero rechaza un valor nulo o de longitud distinta de 8. Después revisa cada carácter. Solo si todas las comprobaciones pasan asigna el dato al campo.
      
          
      
          
      
            
      Patente: normalizar y comparar posiciones
      
            
      patente = patente.trim().toUpperCase();
boolean valida = false;
if (Character.isLetter(patente.charAt(0))
        && Character.isLetter(patente.charAt(1))
        && Character.isLetter(patente.charAt(2))
        && Character.isLetter(patente.charAt(3))
        && Character.isDigit(patente.charAt(4))
        && Character.isDigit(patente.charAt(5))) {
    valida = true; // AAAA12
}
if (Character.isLetter(patente.charAt(0))
        && Character.isLetter(patente.charAt(1))
        && Character.isDigit(patente.charAt(2))
        && Character.isDigit(patente.charAt(3))
        && Character.isDigit(patente.charAt(4))
        && Character.isDigit(patente.charAt(5))) {
    valida = true; // AA1234
}
if (!valida) {
    throw new IllegalArgumentException(
        "La patente debe tener formato AAAA12 o AA1234.");
}
this.patente = patente;
      
            
      Cada charAt(posición) lee una posición de la patente; && exige que todas las posiciones tengan el tipo esperado. El primer bloque acepta 4 letras y 2 dígitos; el segundo, 2 letras y 4 dígitos. El método también comprueba antes que la longitud sea 6.
      
          
      
          
      
            
      Modelo: limpiar y exigir información
      
            
      modelo = modelo.trim();
if (modelo.length() < 2) {
    throw new IllegalArgumentException(
        "Falta mas información del modelo.");
}
this.modelo = modelo;
      
            
      Un modelo como " X " queda como "X", mide un carácter y se rechaza. Un texto de al menos dos caracteres se asigna.
      
          
      
          
      
            
      Año: comprobar el mínimo
      
            
      if (anio < 2015) {
                throw new IllegalArgumentException(
                    "Vehiculos anterior al año 2015 no estan permitidos.");
}
this.anio = anio;
      
            
      El año 2014 produce una excepción; 2015 o un año posterior se guarda. Los booleanos y los campos tipo, color y transmisión se asignan sin validaciones adicionales en sus setters actuales.
      
          
      
        
      

        
      
          
      
            
      ¿Dónde se aplican las reglas?
      
            
      
              El constructor recibe todos los datos y llama a los setters. Por eso, al crear el objeto desde main, las validaciones del modelo se ejecutan automáticamente. Si un dato validado no cumple la regla, se lanza una excepción IllegalArgumentException.
            
      
          
      
          
      
            
      AutomotoraDAO.java · main
      
            
      // Crear el DAO, tal como se hace primero en main
VehiculoDAO dao = new VehiculoDAO();

// Crear el objeto: el constructor valida sus datos
Vehiculo v1 = new Vehiculo(
    "88202601", "ABCD12", "Ferrari", "F8 Tributo",
    2023, false, true, "Superdeportivo",
    "Rojo Furia", "Secuencial F1"
);

// Entregarle el vehículo al DAO
boolean guardado = dao.guardar(v1);
System.out.println(guardado); // true
      
          
      
        
      
        
      
          
      
            Lectura del ejemplo: new Vehiculo(...) llama al constructor; v1 guarda la referencia al objeto creado; new VehiculoDAO() crea un inventario vacío; dao.guardar(v1) pide añadirlo. El resultado true significa que se agregó; false significa que el DAO no lo aceptó.
          
      
        
      
        
      
          
      Detalle importante sobre los valores nulos
      
          
      
            En el código actual, setPatente, setMarca y setModelo llaman a trim() antes de comprobar si el parámetro es null. Por eso, si reciben null, Java lanza NullPointerException antes del mensaje "... es obligatoria". Es una diferencia entre lo que esos métodos parecen querer validar y lo que realmente hacen.
